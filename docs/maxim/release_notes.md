# Release Notes

## November 2026: Reviewed Workspace Through S5

S0-S4 provide local composition, reviewed onboarding, scoped answer memory and
coverage-aware public-feed discovery. S5 adds retained Career-Ops evaluation,
isolated invocation artifacts, exact packet review, manual progress/outcomes,
lossless legacy reconciliation and controlled application ownership with recovery/
latest-state rollback. Rust validates reports, parses GFM trackers and applies
policy without inventing fit scores.

The rejected application planner/mapper/browser runner is retired. Existing private
records are preserved and no production cutover is automatic. Browser/Gmail/
Discord/networking adaptations remain separate stages.
